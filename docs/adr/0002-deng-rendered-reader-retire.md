# deng 渲染读取器退役,官网 IQ 历史数据面成为唯一官方 IQ 趋势来源

deng(众测雷达)重建后 24h IQ 数据岛消失(`iq-body` 空壳、`data-iq-hours`/`total-iq` 归零,2026-09-08 复核维持),spec D9 的「重写渲染读取器 v2」失去读取对象;同周官网 Codex 站主页自挂「IQ 历史数据」(约 3 周×每 4 小时观察点)。2026-09-08 拍板:v1 渲染读取器退役,不再重写渲染路径;实现期先对官网 IQ 历史折叠区做一次端点补勘察(懒加载,本次调研未捕获其请求),拿到公开 JSON 则以新 sidecar 接官网 IQ 趋势卡,勘察失败则下线该趋势卡。本地 IQ 拟合不受影响(与官网曲线本就独立,spec §4.2)。「改拉禁域 API」维持禁止(§5.0)。

## Consequences

- 官网 24h IQ 趋势卡在勘察结果出来前维持 LKG/错误态显示,不做中间态美化。
- 渲染读取器作为「数据面缺失时最后手段」的定位不变(见 CONTEXT.md),未来官网若有只有渲染态的数据,仍可按此模式新开读取器,但不再是 deng。
